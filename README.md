# AI Trening Platform

Treningowy Asystent Kolarza – aplikacja do monitorowania
i planowania treningów kolarskich.

## Stack
- Backend: Python 3.12 + Flask
- Frontend: React + TypeScript + Vite
- Baza: SQLite

## Uruchomienie lokalne
cd apps/api
pip install -r requirements.txt
python src/main.py

cd apps/web
npm install && npm run dev
